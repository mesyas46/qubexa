# Qubexa Platform

Qubexa, öğretmenlerin öğrenci, ders, materyal, sınav, takvim, özel ders ve finans süreçlerini tek çalışma alanından yönetmesini sağlayan dijital öğretmen ofisidir.

## Bileşenler

- `local/qubexa`: Qubexa Workspace ve Core
- `local/qubexa_students`: Öğrenci yönetimi
- `mod/qubexaexam`: Ölçme ve değerlendirme modülü
- `theme/qubexa`: Qubexa tema altyapısı

## Geliştirme Ortamı

- Moodle 4.5
- PHP 8.2
- MariaDB
- XAMPP
