Qubexa Students Framework Phase 1

Bu paket davranışı değiştirmeden lib.php içindeki sorumlulukları ayırır:

- repository: veritabanı sorguları
- service: öğrenci görünüm verileri ve iş kuralları
- output: sayfa template context'i
- template: HTML
- lib.php: ince giriş noktası

Kurulum:
1. ZIP'i açın.
2. İçindeki dosyaları D:\XAMPP\htdocs\qubexa\local\qubexa_students içine kopyalayın.
3. Mevcut lib.php üzerine yazmayı onaylayın.
4. student_panel.js ve styles.css dosyalarınızı değiştirmeyin.
5. Moodle cache temizleyin.
6. Öğrencilerim sayfasını test edin.

Bu paket veritabanına dokunmaz.
